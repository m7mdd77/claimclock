# ClaimClock

Local cash-opportunity deadline and readiness board. Fresh implementation with no external APIs, credentials, spending or automatic submissions. Three synthetic examples are excluded from totals. A recorded receipt is user-provided evidence, not independent verification or a prize guarantee.

Run `npm test`, then `npm start` and open http://127.0.0.1:3251. Data remains in this browser's local storage; export a JSON backup before switching browsers or clearing site data. Imports replace state only after complete validation and confirmation.

Demo: https://claimclock-m7mdd77.choggyacc.chatgpt.site
